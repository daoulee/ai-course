### 관찰 및 분석
1. **행렬 크기가 클 때 (`size = 4000`)**:
   - 수백만 번의 독립적인 행렬 곱셈 연산이 수행되므로, 대규모 병렬 처리에 특화된 GPU(T4)가 CPU에 비해 약 **51배** 압도적으로 빠른 속도를 보였습니다.
2. **행렬 크기가 작을 때 (`size = 100`)**:
   - 데이터와 연산량이 적어 CPU와 GPU의 연산 속도 차이가 거의 없거나, CPU 메모리에서 GPU 메모리(VRAM)로 데이터를 전송하는 오버헤드로 인해 속도 차이가 미미했습니다.
