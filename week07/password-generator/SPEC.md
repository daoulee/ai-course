# 7주차 지정 과제 4: 오타 방지 비밀번호 생성기

강의: https://krchoi.com/lecture/ai/viewer/#week07

## 1. 기술과 파일

- Python 3.10 이상, Flet 1.0. 다른 외부 패키지는 쓰지 않는다. 표준 라이브러리 `secrets`와 `string`은 사용할 수 있다.
- `logic.py`: 비밀번호 생성과 입력 검사. Flet을 import하지 않는다.
- `main.py`: 교수님이 제시한 Flet 1.0 뼈대의 구성 요소와 문법만 사용한다.
- `test_logic.py`: `logic.py`의 결과를 검사한다. 실행 시 통과·실패 수를 출력한다.

## 2. 동작 규칙

1. 소문자는 항상 포함한다. 대문자, 숫자, 특수문자 `!@#$%^&*`는 각각 체크 상자로 선택한다.
2. 길이는 4~32의 정수다. 빈 값, 숫자가 아닌 값, 범위를 벗어난 값이면 생성하지 않고 안내 문구를 보여 준다.
3. 선택된 각 문자 종류는 최종 결과에 적어도 하나씩 들어간다. 선택하지 않은 종류의 문자는 들어가지 않는다.
4. 매 생성은 `secrets`의 무작위 선택을 이용한다. 선택된 종류별 필수 문자 1개씩을 먼저 뽑고, 남은 자리를 전체 허용 문자에서 채운 뒤 순서를 섞는다.
5. `다시 만들기`는 같은 설정으로 새 결과를 만든다. 동일한 결과가 우연히 나올 수 있으므로, 매번 다른 문자열을 보장하지는 않는다.
6. 잘못된 입력 뒤에는 결과 칸을 비운다. 선택 옵션을 바꾸어도 기존 결과는 `만들기` 또는 `다시 만들기`를 누르기 전까지 유지한다.

## 3. 화면

강의 그림처럼 길이 입력, 대문자/숫자/특수문자 체크 상자, `만들기` 버튼, 결과 칸, `다시 만들기` 버튼, 안내 문구를 360×440 창에 둔다. 창 크기 조절은 막는다.

## 4. 내가 정한 추가 기능: 오타 방지 모드

`헷갈리는 문자 제외` 체크 상자를 추가한다. 켜면 대문자 `I`, `O`, 소문자 `l`, `o`, 숫자 `0`, `1`을 허용 집합에서 제외한다. 각 종류는 여전히 비어 있지 않으며 선택된 종류의 문자 1개 이상 규칙을 지킨다. 읽기 어려운 비밀번호를 피하려는 선택 기능이며, 강도를 자동으로 판정하거나 저장하지 않는다.

## 5. 테스트 표

| 입력/설정 | 기대 결과 |
| --- | --- |
| 길이 12, 모든 종류 선택 | 길이 12, 네 종류 각각 1개 이상, 허용 문자만 포함 |
| 길이 4, 선택 옵션 없음 | 소문자 4개 |
| 길이 32, 대문자·숫자 선택 | 길이 32, 소문자·대문자·숫자 각각 1개 이상, 특수문자 없음 |
| 빈 길이, `abc`, `4.5`, `3`, `33` | 빈 결과와 길이 안내 문구 |
| 길이 12, 오타 방지 켬 | `I O l o 0 1` 없음, 선택 종류 규칙 유지 |
| 같은 설정으로 두 번 호출 | 두 번 모두 유효한 결과. 서로 다를 필요는 없음 |

테스트는 무작위 결과의 **형식과 불변 조건**을 검사한다. 특정 문자열을 정답으로 고정하지 않는다.

## 6. 3시간 제작 연습 순서

0~20분에 규칙과 화면 확인, 20~40분에 이 명세와 테스트 표 확정, 40~105분에 `logic.py`와 테스트, 105~155분에 Flet 화면, 155~180분에 실행·수정·최종 검토를 한다.
