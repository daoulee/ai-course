# 4주차 명세 기반 계산기

Python 3.10 이상과 Flet 1.0을 사용한다. `calc.py`가 계산 상태를 처리하고 `main.py`는 버튼과 키보드 입력을 전달한다.

## 설치 및 실행

`week04/calc2` 폴더에서 실행한다.

```bash
python -m pip install "flet[all]==1.0.0"
python test_calc.py
python main.py
```

`test_calc.py`는 `SPEC.md`의 20개 사례를 검사한다. 모두 통과하면 `모든 테스트 통과 (20개)`를 출력하며 종료 코드 0을 반환한다. 실패하면 입력·기대값·실제값을 출력하며 종료 코드 1을 반환한다.

## 조작

- 화면 버튼: 숫자, 소수점, `+`, `−`, `×`, `÷`, `=`, `C`, `⌫`, `+/-`, `%`
- 키보드: 숫자, `.`, `+`, `-`, `*`, `/`, Enter(`=`), Backspace(`BS`), Escape(`C`)
- 계산은 입력 순서대로 즉시 처리한다. 예를 들어 `2 + 3 × 4 =`의 결과는 `20`이다.

2026-10-20 macOS에서 Flet 1.0.0으로 창 표시와 버튼·키보드 입력을 확인했다. Windows에서의 실행은 확인하지 않았다.
