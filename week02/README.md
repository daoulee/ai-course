### 💡 예상과 다른 쌍의 이유 분석
* **2번 (`날씨가 좋다` vs `날씨가 나쁘다`, 0.785) & 4번 (`사과를 먹었다` vs `먹지 않았다`, 0.804)**:
  - 사람 기준으로는 완전 반대 뜻이라 '하'를 예상했으나, 실제 측정값은 0.8 안팎으로 상위권에 들어감.

* **11번 무관한 문장 기준선 (0.459)**:
  - 아무 관계 없는 두 문장이어도 코사인 유사도가 0이 아니라 0.459가 나옴.
  - 모든 문장이 '짧은 한국어 서술문'이라는 형식적 공통점을 가져서 벡터 공간의 특정 영역에 몰려 있기 때문. 즉, 이 모델에서는 **0.5 근처가 사실상 관계없는 바닥값**임을 확인.

## 3. 어텐션(Attention)을 비전공자에게 설명한다면?

1. 사람은 책을 읽을 때 모든 단어를 똑같이 외우지 않고, 중요한 핵심 단어에 형광펜을 칠하듯 집중해서 문맥을 이해.
2. AI 번역기도 마찬가지로 문장을 번역할 때, 지금 출력해야 할 단어와 가장 관련 깊은 원문 단어에 시선을 집중.
3. 예를 들어 영어로 'watched'를 쓰는 순간에는 한국어 원문 맨 뒤에 있는 '봤다'라는 단어에 가장 높은 가중치(시선)를 두고 참조.
4. 이처럼 문맥에 따라 어떤 단어에 얼마나 주의(Attention)를 집중할지 가중치를 매기는 기술이 바로 '어텐션'.
5. 어텐션 덕분에 문장이 길어지거나 단어의 어순이 달라도 기억이 흐려지지 않고, 원문의 의미를 정확하게 파악할 수 있게 됨.

## 4. 핵심 실습 Q&A 정리 (학습 노트)

- **Q1. "날씨 좋다"와 "날씨 나쁘다"는 반대 뜻인데 왜 0.785로 높게 나왔는가?**  
  👉 임베딩 모델이 '날씨'라는 핵심 주제와 문장 구조는 잘 파악하지만, 긍정/부정 같은 반의어 관계는 상대적으로 약하게 반영하기 때문.

- **Q2. `words2d.png` 시각화에서 '배'는 왜 중간에 애매하게 찍혀 있는가?**  
  👉 먹는 '배(과일)'와 타는 '배(탈것)'의 뜻이 둘 다 있는데, 문맥 없이 단어 하나만 주어졌기 때문에 모델이 두 의미의 한가운데 좌표에 점을 놓았기 때문.

- **Q3. 어텐션(Attention)이 뭔지 한 줄로 요약하면?**  
  👉 사람이 책을 읽을 때 중요한 단어에 형광펜을 칠하듯, AI가 단어를 번역하거나 생성할 때 가장 관련 깊은 원문 단어에 시선(가중치)을 집중하는 기술.
