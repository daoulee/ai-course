# 3주차 실습 기록

2026-10-13에 로컬 실습을 다시 실행해 확인한 값이다. 실행 환경과 모델 상태에 따라 시간과 답은 달라질 수 있다.

## 토큰

| 입력 | 토큰 수 |
| --- | ---: |
| `tokens.py` 영화 문장: 한국어 / 영어 | 15 / 8 |
| `tokens.py` 인공지능 문장: 한국어 / 영어 | 14 / 9 |
| `tokens.py` 수도 문장: 한국어 / 영어 | 9 / 6 |
| 추가 문장 `AI 학습 도우미가 강의 노트에서 답을 찾는다` | 18 |

추가 문장은 `Qwen/Qwen3-8B` 토크나이저로 셌다. 같은 뜻의 문장도 언어와 토크나이저에 따라 토큰 수가 다르다.

## Few-shot 정답 수

| 모델 | 예시 0개 | 예시 1개 | 예시 3개 |
| --- | ---: | ---: | ---: |
| `qwen3:1.7b` | 1/5 | 0/5 | 1/5 |
| `qwen3:8b` | 1/5 | 4/5 | 5/5 |
| 실습 서버 `gemma4` | 0/5 | 5/5 | 5/5 |

강의 자료는 실습 서버 모델을 Gemma 4 26B로 소개한다. 이 실험에서 확인한 서버 모델 ID는 `gemma4`이며, 파라미터 수를 별도로 검증하지는 않았다. 예시 수가 늘 때 정답 수가 어떻게 달라지는지 위 표에서 비교할 수 있다.

## 단계별 풀이와 think 모드

| 실습 | 결과 |
| --- | --- |
| 답만 요청한 경우 | 1/5 정답 |
| 단계별 풀이를 요청한 경우 | 5/5 정답 |
| `think=False` | 답 `15`, 0.1초, 출력 3토큰 |
| `think=True` | 답 `9`, 6.8초, 출력 396토큰 |

이번 실행에서는 단계별 풀이와 think 모드에서 정답이 늘었고, think 모드는 출력 토큰과 시간이 더 들었다. 단일 실행 결과이므로 항상 같은 차이가 난다고 해석하지 않는다.

## 실습 파일

`tokens.py`, `stream.py`, `probs.py`, `fewshot.py`, `server.py`, `cot.py`, `think.py`가 있다. 이번 기록의 수치는 토큰·few-shot·단계별 풀이·think 실습에서 얻었다. `stream.py`와 `probs.py`의 실행 결과는 이 기록에 포함하지 않았다. `server.py`는 실습 서버에 접속할 수 있어야 한다.
