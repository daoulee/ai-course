# 할 일 관리 웹앱 스펙

## 1. 개요

할 일을 기록하고 관리하는 웹앱이다. 할 일의 추가, 목록 보기, 완료 표시와 해제, 삭제만 한다.

## 2. 기술

- Python 3.10 이상, Flask
- SQLite (파이썬 내장 `sqlite3` 모듈)
- 화면은 HTML과 CSS만 쓴다

## 3. 파일 구성

| 파일 | 내용 |
| --- | --- |
| `app.py` | Flask 앱과 라우트. 데이터베이스는 `db.py`의 함수만 부른다 |
| `db.py` | 데이터베이스 초기화, 목록 조회, 추가, 완료 전환, 삭제 |
| `templates/index.html` | 목록과 추가 입력창 |
| `templates/error.html` | 오류 화면 (400, 404) |
| `static/style.css` | 화면 스타일 |
| `test_app.py` | Flask `test_client`로 6절을 검사한다. `python test_app.py`로 실행한다 |
| `todo.db` | 데이터 파일. 저장소에 올리지 않는다 |

할 일 테이블: `id` (INTEGER PRIMARY KEY), `title` (TEXT), `done` (INTEGER, 0 또는 1), `created_at` (TEXT, `YYYY-MM-DD HH:MM:SS`)

## 4. 동작 규칙

| 메서드 | 주소 | 입력 | 결과 |
| --- | --- | --- | --- |
| GET | `/` | 없음 | 200. 할 일 목록. 미완료가 위, 완료가 아래. 각각 최근에 만든 것이 위 |
| POST | `/add` | 폼 `title` | 302로 `/`. 실패하면 400과 오류 화면 |
| POST | `/toggle/<id>` | 주소의 번호 | 완료 여부를 반대로 바꾸고 302로 `/`. 없는 번호면 404 |
| POST | `/delete/<id>` | 주소의 번호 | 삭제하고 302로 `/`. 없는 번호면 404 |

제목 규칙

- 앞뒤 공백을 지운 뒤 검사하고, 지운 값으로 저장한다.
- 비어 있으면(공백만 있는 것 포함) 400. "제목을 입력하세요."
- 100자를 넘으면 400. "제목은 100자까지입니다." 100자는 통과한다.

## 5. 화면

- 위쪽: 제목 입력창과 추가 버튼
- 아래쪽: 할 일 목록. 항목마다 제목, 만든 시각, 완료/해제 버튼, 삭제 버튼
- 완료된 할 일은 제목에 취소선을 긋는다
- 할 일이 없으면 "할 일이 없습니다."를 보여 준다
- 오류 화면은 상태 코드와 오류 메시지, 목록으로 돌아가는 링크를 보여 준다

## 6. 테스트

| 요청 | 기대하는 결과 |
| --- | --- |
| `GET /` (비어 있음) | 200, "할 일이 없습니다." 포함 |
| `POST /add` title="공부하기" | 302, 이후 `GET /`에 "공부하기" 포함 |
| `POST /add` title="  테스트  " | 302, "테스트"로 저장 (앞뒤 공백 없음) |
| 두 개 추가 후 `GET /` | 나중에 추가한 것이 먼저 나온다 |
| 먼저 추가한 것을 완료한 뒤 `GET /` | 완료한 것이 미완료보다 아래에 나온다 |
| `POST /toggle/1` (있는 번호) | 302, 1번이 완료로 바뀐다 |
| `POST /toggle/1` 한 번 더 | 302, 1번이 미완료로 돌아온다 |
| `POST /delete/1` (있는 번호) | 302, 1번이 목록에서 사라진다 |
| `POST /add` title="" | 400, "제목을 입력하세요." 포함 |
| `POST /add` title="   " | 400, "제목을 입력하세요." 포함 |
| `POST /add` title="가" * 100 | 302 (경계값 통과) |
| `POST /add` title="가" * 101 | 400, "제목은 100자까지입니다." 포함 |
| `POST /toggle/999` (없는 번호) | 404 |
| `POST /delete/999` (없는 번호) | 404 |

## 7. 완료 전 점검

- `python test_app.py`가 전부 통과한다.
- 서버를 껐다 켜도 목록이 남아 있다.
- 브라우저에서 추가, 완료, 해제, 삭제를 한 번씩 해 본다.
- 외부 CSS, 자바스크립트를 불러오는 줄이 없다.
