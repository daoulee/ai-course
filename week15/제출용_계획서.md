# 기말 프로젝트 계획서: 대학 출석 누락 방지 서비스

## 불편했던 상황
대학생이 수업에 참여하고도 스마트폰 출석 앱에서 출석 버튼을 제때 누르지 못해 출석을 누락할 수 있다. 여러 수업의 요일과 시작 시간을 따로 확인해야 해 다음 수업과 출석 확인 시점을 놓치기도 한다.

## 해결 방법과 목표
스마트폰에서 수업 일정을 등록하고 오늘 수업과 다음 수업을 확인해 출석을 챙길 수 있도록 한다. 등록된 일정에 맞춘 알림을 목표로 하며, 실제 학교의 출석 처리·상태 조회는 공식 연동 가능성이 확인되기 전까지 구현된 것으로 표시하지 않는다.

## 만들 기능
- 수업명, 요일, 시작 시각, 강의실을 입력해 기기에 저장하고 목록을 확인·삭제한다.
- 현재 시각을 기준으로 오늘의 수업과 가장 가까운 다음 수업을 표시한다.
- 기기에서 수업 확인을 돕는 로컬 알림을 단계적으로 검증한다. 수업 일정과 알림의 자동 연결은 구현 및 검증 대상이다.
- 실제 연동이 없는 학생 정보와 학교생활 정보는 연동 전 상태로 표시한다.

## 개발 환경
Flutter를 사용해 스마트폰에서 실행되는 앱으로 만들고, 실습 서버의 gemma4를 사용해 구현한다. 학교 서버 및 실제 출석 시스템과의 연동 가능성은 미확인이다.

## 단계와 확인 방법
1. **기획:** 출석을 놓치는 상황과 기능 범위를 정리하고 실제 연동 여부를 구분한다.
2. **수업 관리:** 수업 등록·조회·삭제 후 앱을 다시 열어 저장 여부를 확인한다.
3. **다음 수업 계산:** 당일, 요일 변경, 다음 주 및 연말 경계를 테스트한다.
4. **알림:** 권한, 예약, 포그라운드·백그라운드 등의 시나리오를 기기별로 시험하고 실제 도착 여부를 기록한다.
5. **통합:** 스마트폰 화면에서 등록부터 목록 갱신까지 확인하고, 각 단계의 결과와 미검증 항목을 기록한다.

## 범위와 제약
실제 출석 완료나 휴강 여부는 확인하지 못한다. 학교 계정, 학생증 QR, 학식과 버스의 실제 데이터는 공식 연동이 확인되기 전까지 제공하지 않는다. 예약 알림의 기기별 동작과 실제 학교 연동 가능성은 별도로 검증해야 한다.
